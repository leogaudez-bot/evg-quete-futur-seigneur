# La Quête du Futur Seigneur

Party game web mobile-first pour EVG médiéval, pensé pour être joué à plusieurs autour d’un téléphone.

## V2 — Tournoi multi-participants

- Maisons / équipes automatiques
- Roue du destin
- Mini-jeux : duels, votes, défis équipe, photo, vidéo, procès, finale
- Timer dramatique
- Dé royal
- Réactions live visuelles
- Score par maison
- Carte de progression
- Liens d’inspiration médias libres / sûrs
- Images générées intégrées localement

## Lancer en local

```bash
npm install
npm run dev
```

## Tester

```bash
npm test
npm run build
```

## Déploiement

GitHub Pages via `.github/workflows/deploy.yml`.
